## 🛡️ ما هو سَنَد؟

أول منصة تطبّق **علم الإسناد** — أدق نظام تحقق عرفته البشرية منذ ١٢٠٠ سنة — على أخبار اليوم، بسرب وكلاء ذكاء اصطناعي.

**المحرك:**  
`4 وكلاء رصد` ← Google News RSS (أخبار حية) ← `بروتوكول إسناد مبني على خمسة معايير من علم الحديث` ← `وكيل محلّل (Gemini)` ← حكم: **صحيح / حسن / مردود**

---

## 🔬 بروتوكول الإسناد (SANAD Protocol)

| المعيار | التطبيق الرقمي |
|--------|----------------|
| **الإسناد** | سلسلة الجلب: مصدر أصلي ← ناقل ← سرب سَنَد |
| **عدالة الراوي** | سجل الرواة ٤ طبقات: وكالات رسمية / وكالات دولية / قنوات / ناقل مجهول |
| **الضبط** | التوثيق الزمني: تاريخ + ساعة + مصدر أصلي |
| **الشاهد** | نفس الخبر من مصدرين مستقلين → ترقية: حسن → صحيح |
| **نقد المتن** | حاكم الإسناد (Gemini) يرفض الخبر المتناقض أو المستحيل |

**+ ISO/IEC 27037** — سلسلة العهدة الجنائية الرقمية

## 🚀 التشغيل

### خيار ١ — مباشر (بدون server)
```bash
# افتح index.html في المتصفح — لا يحتاج backend
open index.html
```

### خيار ٢ — Netlify Drop
اسحب `index.html` إلى [netlify.com/drop](https://app.netlify.com/drop)

### خيار ٣ — نشر مباشر (Netlify CLI)
```bash
netlify deploy --dir=. --prod
```

---

## 🔑 تفعيل الوكيل المحلّل (اختياري — مجاني)

١. اذهب لـ [aistudio.google.com/apikey](https://aistudio.google.com/apikey)  
٢. أنشئ مفتاح مجاني (Gemini Flash — لا يحتاج بطاقة)  
٣. في المنصة: اضغط زر **🧠 حاكم الإسناد** والصق المفتاح  
٤. المفتاح يُحفظ في متصفحك فقط — لا يُرسل لأي خادم غير Google
